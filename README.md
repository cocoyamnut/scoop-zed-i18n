# scoop-zed-i18n

> Package definitions install the verified cocoyamnut v1.25.2-i18n.1 release. Future automatic synchronization requires a separately configured packaging token.

This repository is a fork of [LI-NA/scoop-zed-i18n](https://github.com/LI-NA/scoop-zed-i18n). Original licensing and attribution are preserved.

Scoop bucket for [Zed i18n](https://github.com/cocoyamnut/zed-i18n), a localized build of the Zed editor.

For project details, release notes, source code, and issue tracking, please use the main repository:

https://github.com/cocoyamnut/zed-i18n

## Install

```sh
scoop bucket add zed-i18n https://github.com/cocoyamnut/scoop-zed-i18n
scoop install zed-i18n/zed-i18n
```

The universal build includes all 13 supported languages.
